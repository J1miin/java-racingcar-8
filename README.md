# java-racingcar-precourse

 ## 자동차 경주 기능 목록

 ### 1. 프로그램 진입
- [X] 1.1 사용자가 자동차 이름을 입력할 수 있도록 안내하는 문구를 출력하는 기능
- [X] 1.2 사용자가 문자열을 입력하는 기능
  - [X] 1.2.1 입력값: 문자열


### 2. 경주 게임 구현
- [X] 2.1 자동차 클래스
  - [X] 2.1.1 자동차 이름을 저장하는 기능 
  - [X] 2.1.2 자동차 별 누적 이동 거리 저장하는 기능
  - [X] 2.1.3 자동차의 랜덤 숫자를 관리하는 기능

- [X] 2.2 자동차 매니저 클래스
  - [X] 2.2.1 사용자 입력으로 받은 이름 , 기준으로 분리하는 기능
  - [X] 2.2.2 전체 자동차를 리스트로 관리하는 기능
  - [X] 2.2.3 자동차 하나하나의 객체를 생성하는 기능
     
- [X] 2.3 경주 클래스
  - [X] 2.3.1 자동차 별 랜덤 숫자 추출하는 기능
  - [X] 2.3.2 랜덤 숫자 기준으로 이동 또는 멈추는 기능
  - [X] 2.3.3 최종 우승자를 찾는 기능

 
### 3. 출력
- [X] 3.1 경기마다 자동차의 이동 거리 출력하는 기능
- [X] 3.2 우승자 출력하는 기능


### 4. 예외처리
- [X] 사용자가 잘못된 입력을 한 경우 IllegalArgumentException을 발생시킨 후 애플리케이션 종료
  - [X] 4.1 자동차 이름과 관련한 입력
    - [X] 4.1.1 입력값이 없는 경우
    - [X] 4.1.2 쉼표 뒤에 공백이 있는 경우
    - [X] 4.1.3 동일한 이름이 나오는 경우
  - [X] 4.2 시도할 횟수와 관련한 입력
    - [X] 4.2.1 숫자가 아닌 문자가 오는 경우
    - [X] 4.2.2 정수가 아닌 입력이 들어오는 경우
    - [X] 4.2.3 0보다 작은 정수가 나오는 경우
