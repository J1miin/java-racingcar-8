# java-racingcar-precourse

 ## 자동차 경주 기능 목록

 ### 1. 프로그램 진입
- [ ] 1.1 사용자가 자동차 이름을 입력할 수 있도록 안내하는 문구를 출력하는 기능
- [ ] 1.2 사용자가 문자열을 입력하는 기능
  - [ ] 1.2.1 입력값: 문자열

### 2. 경주 게임 구현
- [ ] 2.1 자동차 클래스
  - [ ] 2.1.1 사용자 입력으로 받은 이름 , 기준으로 분리하는 기능
  - [ ] 2.1.2 자동차 별 누적 이동 거리 저장하는 기능

- [ ] 2.2 경주 클래스
  - [ ] 2.2.1 전체 시도 횟수 관리하는 기능
  - [ ] 2.2.2 전체 시도 횟수 만큼 경기 진행하는 기능
    - [ ] 2.2.2.1 자동차 별 랜덤 숫자 추출하는 기능
  - [ ] 2.2.3 한 경기마다 자동차 별 이동 거리 관리하는 기능

- [ ] 2.3 결과 클래스
  - [ ] 2.3.1 최종 우승자를 찾는 기능

  
### 3. 출력
- [ ] 3.1 경기마다 자동차의 이동 거리 출력하는 기능
- [ ] 3.2 우승자 출력하는 기능
  - [ ] 3.2.1 단독 우승자 출력하는 기능
  - [ ] 3.2.2 공동 우승자 출력하는 기능


### 4. 예외처리
- [ ] 사용자가 잘못된 입력을 한 경우 IllegalArgumentException을 발생시킨 후 애플리케이션 종료
  - [ ] 4.1 자동차 이름과 관련한 입력
    - [ ] 4.1.1 입력값이 없는 경우
    - [ ] 4.1.2 쉼표 뒤에 공백이 있는 경우
    - [ ] 4.1.3 동일한 이름이 나오는 경우
  - [ ] 4.2 시도할 횟수와 관련한 입력
    - [ ] 4.2.1 숫자가 아닌 문자가 오는 경우
    - [ ] 4.2.2 정수가 아닌 입력이 들어오는 경우
    - [ ] 4.2.3 0보다 작은 정수가 나오는 경우
